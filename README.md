## 🚀 Featured Project

<details>
<summary><strong>☁️ Cloud DevOps Portfolio Pipeline</strong></summary>

<br>

A hands-on Cloud & DevOps project where I built a portfolio website and created an automated deployment pipeline using **GitHub Actions, Docker, Docker Compose, SSH, and AWS EC2**.

Instead of manually deploying every change, the pipeline automatically deploys updates whenever code is pushed to the `main` branch.

| Category           | Details                                                                                             |
| ------------------ | --------------------------------------------------------------------------------------------------- |
| **Stack**          | HTML • CSS • JavaScript • Git • GitHub Actions • Docker • Docker Compose • Nginx • AWS EC2 • Ubuntu |
| **Deployment**     | GitHub Actions → SSH → AWS EC2 → Docker Compose                                                     |
| **Automation**     | Automated deployment after `git push`                                                               |
| **Infrastructure** | AWS EC2 running Ubuntu Linux                                                                        |
| **Security**       | SSH authentication + GitHub Secrets + AWS Security Groups                                           |
| **Monitoring**     | Uptime Kuma                                                                                         |
| **Repository**     | [View Project](https://github.com/amanbir413/linux-devops-pipeline)                                 |
| **Status**         | Active / Improving                                                                                  |
